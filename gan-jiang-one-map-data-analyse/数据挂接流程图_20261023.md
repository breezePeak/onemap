# 数据挂接流程图

依据：[数据挂接逻辑详细说明](F:/lin_shi_project/gan-jiang-one-map-data-analyse/数据挂接逻辑详细说明_20261023.md)。日期：2026-10-23。

共 10 张图。绿色为满足限定条件的明确结果，黄色为候选或待核对，红色为冲突、异常或阻断。图中的“明确归属”和“自动填空”分别判断；名称相近、目录命中、空间相交均不能单独保证字段自动采用。

## 图 1：业务总流程

```mermaid
flowchart TD
    A[上传目标工作簿] --> B[逐行建立项目身份 row-行号]
    B --> C[盘点台账、图层、文件与压缩包成员]
    C --> D[优先读取供应扫描件及跨阶段全文材料]
    D --> E[PDF原生文字、页面渲染与OCR]
    E --> F[读取附件SHP、CAD及配准图件]
    F --> G[确定参考范围并计算空间关系]
    G --> H[按页内实体判断归属并提取字段候选]
    H --> I[按新编号、别名、指纹扩展检索，最多3轮]
    I --> J[汇总阶段挂接、整体争议与字段冲突]
    J --> K[建立符合条件的自动补丁]
    K --> L[合并工作台逐单元格候选]
    L --> M[人工核对、选择与归属确认]
    M --> N[导出采用值、来源及待核对清单]
    B -.-> O[档案编号可重复，只作检索线索]
    N -.-> P[检索完成不代表所有材料均已成功识别]
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    class O,P pending
```

## 图 2：文件检索与再次扩展

```mermaid
flowchart TD
    A[目标编号、档案号、名称、地址与人工别名] --> B[建立并补充检索词]
    B --> C[扫描普通文件及已盘点的压缩包成员]
    C --> D{命中当前排除规则或不支持格式?}
    D -->|临时锁文件或被排除路径| X[跳过当前文书检索分支]
    D -->|格式无法读取| Y[记录解析待办]
    D -->|可处理| E{路径命中编号、名称或地址?}
    E -->|是| F[列为优先读取的检索候选]
    E -->|否| G[进入全文扫描，仍可发现项目线索]
    F --> H[读取原生文字或OCR]
    G --> H
    H --> I[页内归属和字段候选分析]
    I --> J[新编号、已核实别名及同字节PDF附件线索]
    J --> K[扩展相关目录和材料]
    K --> L{无新增来源且归属关系不再变化?}
    L -->|是| M[结束扩展]
    L -->|否，未满3轮| H
    L -->|否，已满3轮| N[记录未收敛，可再次检索]
    X -.-> W[当前含身份证、授权、委托等路径关键词排除，可能漏检混合业务文件]
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    classDef blocked fill:#fde2e2,stroke:#c43b3b,color:#531616
    class F,N,Y pending
    class X,W blocked
```

说明：名称模糊检索阈值为 0.80，保留业务描述参与比较。附件指纹要求字节完全相同；同文书重新扫描不保证命中。指纹关系主要扩大检索，不直接批准字段回填。

## 图 3：结构化记录的精确与模糊匹配

```mermaid
flowchart TD
    A[目标记录与来源记录] --> B[标准化编号、名称、地址及面积]
    B --> C[计算编号命中、编号冲突、四至冲突及相似度]
    C --> D{有无冲突的精确候选?}
    D -->|一条| E{至少一项命中不是推断编号?}
    D -->|多条| F{恰好一条命中监管号、合同号或单元号?}
    F -->|是| E
    F -->|否| G[AMBIGUOUS：保留多条精确候选]
    E -->|是| H[MATCH_EXACT：精确记录对应]
    E -->|否| I[NEEDS_FUZZY：推断编号仍需确认]
    D -->|没有| J{存在编号命中但有冲突的候选?}
    J -->|是| K[CONFLICT：不以名称相似抵消冲突]
    J -->|否| L{候选池为空?}
    L -->|是| M[NOT_FOUND：未找到记录]
    L -->|否| N{前两名综合分差小于0.08?}
    N -->|是| O[AMBIGUOUS：模糊候选接近]
    N -->|否或只有一条| P[NEEDS_FUZZY：排序后供人工核对]
    H --> Q[仍须进入单元格采用判断]
    classDef good fill:#dff3e4,stroke:#31824c,color:#153e23
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    classDef blocked fill:#fde2e2,stroke:#c43b3b,color:#531616
    class H good
    class G,I,O,P,M pending
    class K blocked
```

候选池准入：编号精确命中，或名称相似度≥0.45，或地址相似度≥0.65，或面积误差≤2%。综合分为 `0.55×名称 + 0.25×地址 + 0.20×面积得分`。模糊综合分仅用于排序，没有按高分直接自动通过的规则。

## 图 4：页面拆分、OCR纠错与项目归属

```mermaid
flowchart TD
    A[PDF文字或OCR页面] --> B{能可靠区分页内多个实体?}
    B -->|表格行、重复项目标签或明确双栏| C[拆成独立实体段，字段在段内提取]
    B -->|不能| D[保留整页，不强行拆分]
    C --> E[提取名称、业务编号、地址四至与字段标签]
    D --> E
    E --> F[OCR单字符形近编号只生成唯一建议，保留原文]
    F --> G{名称或已有监管号、合同号、单元号形成唯一强归属?}
    G -->|是| H{存在编号冲突、多个项目名称或相反四至?}
    H -->|没有| I[记录明确项目归属]
    H -->|有| J[保留冲突，不能确认归属]
    G -->|否| K[按检索线索、名称、地址和面积产生候选]
    K --> L{有待确认项目?}
    L -->|有| M[保存待确认项目列表]
    L -->|没有| N[保存为未关联材料]
    I --> O[提取阶段字段，作为人工核对候选]
    M --> O
    J --> N
    F -.-> P[项目代码单独命中不确认页内归属]
    classDef good fill:#dff3e4,stroke:#31824c,color:#153e23
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    classDef blocked fill:#fde2e2,stroke:#c43b3b,color:#531616
    class I good
    class M,N,O,P pending
    class J blocked
```

说明：归属判断在每个实体内进行。导出仍按“页面＋实体段”保留边界；同一实体的PDF文字与OCR矛盾会形成冲突。当前仅处理有限版式和单字符纠错。

## 图 5：空间参考范围与相交候选

```mermaid
flowchart TD
    A[主图层、附件SHP、CAD和配准候选] --> B{坐标已知、可转换且几何可用?}
    B -->|否| C[进入坐标或读取待确认清单]
    B -->|是| D[转换到供地图层参考投影坐标系]
    D --> E{供地有精确无冲突命中?}
    E -->|是| I[同层命中图斑取并集，建立参考范围]
    E -->|否| F{首登单元号有精确无冲突命中?}
    F -->|是| I
    F -->|否| G{报批文号有精确无冲突命中?}
    G -->|是| I
    G -->|否| H{附件属性有精确无冲突命中?}
    H -->|是| I
    H -->|否| J[各图层分别保留最多5个无冲突模糊范围候选]
    I --> K{命中依据全是未确认推断编号?}
    K -->|是| L[参考范围仍待确认]
    K -->|否| M[记录参考图层与定位依据]
    J --> N[分别计算候选空间关系]
    L --> N
    M --> N
    N --> O[计算相交面积及双向覆盖率]
    O --> P[过滤微小相交；编号直接命中但不相交时仍保留核对]
    P --> Q[进入多批次并集和跨项目争议判断]
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    class C,J,L pending
```

普通相交门槛为 `max(1平方米, 参考范围面积×0.1%)`。附件仅在 `READY` 且有正面积面几何时参与。报批锚点可能是整批范围，不代表项目独占范围；存在空间候选也不直接代表可自动填字段。

## 图 6：多宗地、多批次与整体争议

```mermaid
flowchart TD
    A[参考范围及各层相交结果] --> B[按批复文号、单元号等分组]
    B --> C[各组交集取并集，计算覆盖率和重复面积]
    C --> D[检查供地、宗地、附件几何是否被多个项目使用]
    D --> E{存在跨项目共用争议?}
    E -->|没有| F[整体关系未因共享争议被阻断]
    E -->|有| G{存在有效人工范围确认?}
    G -->|全部相关项目确认共用| F
    G -->|唯一独占归属| H[仅归属项目保留资格，其他项目排除]
    G -->|未确认或确认相互矛盾| I[形成争议连通组，阻断自动采用]
    G -->|明确排除| J[排除相应参考范围]
    F --> K[继续按具体字段的采用条件判断]
    H --> K
    I --> L[输出整体挂接消歧清单，等待核对]
    J --> L
    classDef good fill:#dff3e4,stroke:#31824c,color:#153e23
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    classDef blocked fill:#fde2e2,stroke:#c43b3b,color:#531616
    class F good
    class L pending
    class I,J blocked
```

说明：允许一个项目对应多宗地、多批次。共同使用报批批次本身不按宗地独占争议处理。当前保留关系并阻断歧义，不自动推断项目拆分或合并。

## 图 7：空间证据自动补批复文号与日期

```mermaid
flowchart TD
    A[空间结果] --> B{参考范围来自已确定供地图斑?}
    B -->|否| X[保留空间候选，不生成此类自动补丁]
    B -->|是| C{整体关系允许采用且未被排除?}
    C -->|否| X
    C -->|是| D{表内为有效数值且单位为平方米?}
    D -->|是| E{图斑与声明面积差异不超过2%?}
    E -->|否| X
    E -->|是| F[排除人工判为不一致的目标]
    D -->|否，此处未作同等面积核查| F
    F --> G[按批复文号计算交集并集覆盖]
    G --> H{恰好一个文号组覆盖至少98%?}
    H -->|否| X
    H -->|是| I{其他每个文号组覆盖均小于1%?}
    I -->|否| X
    I -->|是| J[提出批复文号补丁，日期有效时另提日期补丁]

    classDef good fill:#dff3e4,stroke:#31824c,color:#153e23
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
```

说明：不复制整批面积，不用批次名称代替日期。此处明确画出当前面积单位检查的限制，不能将其理解为所有单位均通过同等核查。

```mermaid
    C -->|保留原值| D[原值保持不变]
```

## 图 9：人工反馈与配准如何进入重算

```mermaid
flowchart TD
    A[人工核对] --> B[保存名称、地址或道路别名]
    A --> C[提供并验证附件坐标系]
    A --> D[确认范围共用、独占、排除或撤销]
    A --> E[原件与图斑判读：一致、不一致、待核实]
    A --> F[在图件及地图选择至少4组同名控制点]
    F --> G{控制点、仿射变换和最大残差通过?}
    G -->|否| H[重新选择控制点]
    H --> F
    G -->|是| I[生成配准图、PGW、PRJ及红色闭合区域候选]
    I --> J[参与后续附件空间计算，边界仍需核对]
    B --> K[更新检索身份与候选依据]
    C --> K
    D --> K
    E --> L{原件和相关几何版本仍有效?}
    L -->|否| M[旧判读失效，需重新核对]
    L -->|是| N[一致可帮助归属；不一致排除关系；待核实不升级证据]
    N --> K
    K --> O[重算字段、矢量、空间、补丁及工作台候选]
    J --> O
    O --> P[有效人工选择保留，失效候选提示重新选择]
    classDef pending fill:#fff3cd,stroke:#b58100,color:#332500
    class H,J,M,P pending
```

说明：控制点拟合默认最大残差容限 2 米，以提交值为准；低残差不等于真实测绘精度。配准保存后生成的附件在后续空间计算中使用，不表示仅点击保存即已经完成所有重算。

## 图 10：补建项目与来源异常
