## 二、关键技术实现细节

### 1. 七阶段标准定义与非业务目录隔离（`scripts/source_config.py`）
- 定义完整的七个业务阶段：
  - `S1`: `1.用地预审与选址`（用地预审与选址）
  - `S2`: `2.条件出具`（规划条件和用地红线出具）
  - `S3`: `3.批次报批阶段`（用地报批）
  - `S4`: `4.土地供应阶段`（土地供应）
  - `S5`: `5.土地首次登记`（土地首次登记）
  - `S6`: `6.用地规划`（用地规划）
  - `S7`: `7.工程规划`（工程规划）
- 自动隔离排除非业务目录：`收储材料`、`数据图层`、`计划供应`。

### 2. 独立文书自动规整（`scripts/organize_independent_documents.py`）
- 针对 S2 `规划条件盖章版` 下 `2024年用地规划条件`、`2025年用地规划条件` 及子目录中散落的单体 PDF 规划条件文书；
- 自动为其就地创建同名文件夹（如 `赣新直管2025-001地块-lkq102-c08规划条件/`），并将文件安全移入其中，使得每个单体文书均具备独立项目大目录地位。

### 3. 项目大目录判定引擎与 SQLite 优先查库缓存（`scripts/project_catalog.py`）
- **持久化表设计**：在 `work/folder_mount/project_catalog.sqlite` 中建立 `projects` 表与索引，记录各阶段业务项目大目录节点。
- **优先查库机制**：
  - 第一优先级：材料查询时，优先检索 SQLite 数据库中的大项目路径前缀；若命中，直接复用已有大目录判定，耗时 0 毫秒，绝不重复分析；
  - 第二优先级：未命中时执行业务研判，确定项目大目录后立即 `INSERT ... ON CONFLICT` 存入 SQLite 与 JSON 镜像；
  - 人工保护：人工标记（`manual` 或 `confirmed`）的大目录在查库时优先锁定，防被覆盖。

### 4. M2 精确关联大目录聚合（`scripts/folder_mount.py`）
- 废除旧版只比相邻阶段（S1→S2→S3→S4）的限制，支持 7 阶段任意两两组合比较（最多 21 组）；
- 附件 SHA-256 命中后从小目录向上归属至双方项目大目录；
- 同一对大目录间命中的多份附件聚合为一条候选关系、多条支撑证据；
- 证据数据中清晰保留两侧的“命中小目录路径”与“原始文件逻辑路径”。

### 5. 专属技能封装（`onemap-stage-mount`）
- 技能文件：`C:\Users\Administrator\.gemini\config\skills\onemap-stage-mount\SKILL.md` 与 `docs/skills/onemap-stage-mount/SKILL.md`；
- 一键执行入口：`python scripts/run_stage_mount.py`，支持随时重跑全流程。
