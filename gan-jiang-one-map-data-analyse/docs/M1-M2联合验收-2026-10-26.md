# OneMap 第一阶段：项目大目录智能识别 + M1/M2 联合关联与前端收敛验收报告（2026-10-26）

## 一、职责边界与第一阶段闭环说明

1. **第一阶段核心范围**：
   - Agent 依据 `onemap-stage-mount` Skill 智能识别七阶段项目大目录（区分 `project`、`collection`、`classification`、`material`、`unresolved` 五类节点），经真实磁盘路径校验后持久化存库。
   - **M2（相同附件关联）**：基于有效材料完整 SHA-256 指纹建立跨阶段全部 21 组阶段对关联。
   - **M1（完整项目代码关联、补漏与交叉校验）**：提取标准化完整项目代码，对 M2 结果进行交叉印证与冲突检测，并补充 M2 未覆盖的跨阶段关联。
   - **前端收敛与人工审核**：前端仅保留 **`1 · 目录关联`** 与 **`2 · 冲突管理`** 两个核心视图，供用户搜索筛选、查看证据与 PDF 页码定位、处理冲突及查看审核历史。
2. **严格隔离非第一阶段能力**：
   - 前端已彻底移除“提取项目数据”模块、“数据制表”模块、Excel 上传回填、自动补全、Excel 导出下载、治理成果自动生成、任务与数据管理弹窗，以及“扫描 / 更新目录关联”按钮。
   - 后端 `app/server.py` 已禁用 `/api/jobs`、`/api/current`、`/api/jobs/*`、`/api/datafiles`、`/api/storage` 及 `POST /api/folder-mount/scan`（均返回 HTTP `403`），底层脚本保留但不在第一阶段暴露或调用。
