## 实现与数据规则

`material_evidence.PATTERNS['project_code']` 为唯一共享完整代码正则，`canonical_code()` 统一 NFKC、大小写、明确横线和排版空格。M1 保存原始字符，不自动把 OCR 的 O/I/L 等改为数字，不按名称、地址、年份或局部编号推测。格式之外，限制 ASCII 标准化结果、年份1900～2099及非全零地区段；这属于语法筛查，不等同于官方项目库存在性校验。

来源分为正文字段、结构化字段、文件名、项目目录、子目录，优先级依次为100、100、80、70、60。正文须有明确“项目代码”标签，结构化数据须有对应键/表格标签。优先级只描述来源，不覆盖其他代码。所有代码及位置保留；多代码、非法完整代码、读取失败或无法可靠识别字段标记目录需复核。不同阶段同码使用字典索引连接；按阶段组合只枚举该码的实际候选，不遍历全部目录对。一对多、多对一、多对多均保留，全部自动关联仅为候选/需复核。

读取范围：目录和文件名、原生文字 PDF、DOCX、XLSX/XLSM、TXT/MD/CSV/XML、JSON 的 `project_code`/`项目代码` 字段。PDF 复用已有45秒限时读取函数；版本完整匹配时复用原生文字缓存。图片、旧 DOC/XLS、未知格式和超过20MB文本/DOCX XML记录跳过，不启动全量 OCR。未绑定源版本的旧 OCR/页内候选不作为精确证据。真实页码、段落、单元格、JSON位置或字符位置保留；PDF预览可跳转实际页码，不虚构页码。

SQLite `project_catalog.sqlite` 新增：

| 表 | 内容 |
|---|---|
| `project_codes` | 目录ID、标准代码及完整 JSON 证据：原文、阶段、编码类型、来源类型、路径、真实位置、优先级、可信度、冲突、源版本、解析版本 |
| `project_code_cache` | 逻辑来源、大小/mtime/ctime、解析版本、已抽取代码片段、跳过原因；不缓存读取失败，不重复保存全文 |

`result.json` 新增 `methods`、`project_code_index`、`m1_statistics`、`skip_statistics`；目录关系继续沿用双方目录ID生成的关系ID，同一目录对只保留一条关系，新增 `methods`、`method_evidence`、`method_signatures`、`review_context`。M2 独立执行保持原哈希签名算法；联合签名组合方法签名。`decisions.json` 保留人工决定、方法签名、上下文和历史，派生当前状态；新增方法、源证据或边界/歧义上下文变化进入需复核，并展示原决定。每次人工改判继续追加历史；不会把旧确认直接套在新增证据上。

当前界面展示最近一次成功运行所选方法的结果；`result-M1.json`、`result-M2.json` 保留各方法最近运行快照，联合快照通过 `method_evidence` 区分。未选方法的历史证据不自动混入新扫描结果，避免展示未经重扫的过期证据。

目录身份使用阶段及相对目录生成的ID，代码不能充当主键。人工调整边界保留目录ID，SQLite同步更新 `project_root`，并要求重扫；边界上下文变化需复核。自动检测到目录迁移时生成新目录ID，不自动继承旧审核；原决定留存供追溯。数据源根路径变化也不自动继承旧证据。代码缓存使用路径作为查找键，不作为项目身份；源版本变化失效、删除材料清缓存。`extract_pdfs.py` 为原生缓存补充ctime，旧版缺少该值的缓存重新读取，避免已发生可检测版本变化的文件复用旧文字。元数据缓存无法识别刻意保留大小和全部文件时间戳的原位改写，此类数据需先清缓存；Windows ctime是创建时间，不能视为内容修改时间。

## M2 必要修复

1. S2年份/规划条件汇编仅为分类层，旧自动分类记录保留在SQLite供追溯，但退出可用项目和前缀缓存；手工边界保留。扫描的 `__node__` 占位符不再进入项目路径。
2. Web与脚本使用相同异常策略：已知压缩包损坏、加密、CRC/大小校验异常记录跳过；越界、链接、并发版本变化、工具缺失、磁盘空间不足及未验证材料覆盖风险默认阻断。旧 `tolerate_corrupted` 参数不能放宽安全边界；脚本阻断时返回非零并保留上次成功结果。
3. `file_count` 是去重后的材料条目，空文件、PRJ/CPG/TMP及内部临时文件不进入有效材料；`skip_statistics.reasons` 明确说明差额。M2对有效材料计算/复用哈希；M1单独执行不新增哈希，可复用已有有效缓存。扫描异常和无法读取的压缩成员单列，不能把条目数当成成功材料数。
4. 审核弹窗使用七阶段配置，补全21组筛选，修复项目视图跨阶段组合筛选；保留50行分页、20条证据分页和人工操作，增加方法筛选。
5. 扫描阶段正确使用闭包当前阶段；索引首条和M1分段进度按真实材料阶段上报。
