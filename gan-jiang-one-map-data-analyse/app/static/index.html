置信度评分标准

  • 100%
    目录结构清楚

    目录边界清晰，内部文书、图件或表格指向同一项目/同一批次/同一许可证或宗地单元，无跨项目混装。

  • 60%
    部分存疑 / 待核对本目录边界

    本文件夹主材料指向同一项目，但本阶段内存在同名分卷、多宗地并宗/延期合卷或待归属区同名目录，需核实本文件夹边界与材料完整性（不涉及跨阶段关联）。

  • 40%
    多对象混杂 / 冲突 / 损坏

    同一目录混装多个不同项目或地块、内部编号（批复/合同/证号/地籍号）冲突，或压缩包损坏无法核验，需人工拆分或排障。

  • 0%
    空目录 / 无效残留

    目录内无任何有效业务文件（仅剩空文件夹或残片），不构成有效项目资料包。
